### Hi, I'm Barend 👋

I build software in Go, mostly tools and retro emulators, and I like taking
projects all the way: tests, CI, docs, and a version you can try in your
browser. I build with AI coding agents. I'm also versed in Python, and over
the years I've worked with PHP, JavaScript, Java and C/C++.

I work at RMIT University Vietnam on Student Administration Systems, using
Oracle PeopleSoft and previously LiveCode.

#### 🕹️ Emulators and retro computing

- **[Chippie](https://github.com/rbscholtus/chippie)**: a CHIP-8 emulator
  dressed as a 1970s TV. Plays about 300 CHIP-8, SUPER-CHIP and XO-CHIP games
  with the right quirks for each. Go → WebAssembly, tested against the
  Timendus test suite. [▶ Play in your browser](https://rbscholtus.github.io/chippie/)
- **[go-comx](https://codeberg.org/barendscholtus/go-comx)**: a cycle-accurate
  emulator, in Go, of the COMX-35 vintage home computer (PAL variant).
  [📝 Write-up](https://www.reddit.com/r/retrobattlestations/comments/1teqhom/built_a_cycleaccurate_comx35_emulator/)
- [chippie-rust](https://github.com/rbscholtus/chippie-rust): my first CHIP-8
  interpreter, in Rust with egui, for the browser and the desktop.
  [▶ Try it](https://rbscholtus.github.io/chippie-rust/)
- [cosmacelf.js](https://github.com/rbscholtus/cosmacelf.js): an emulator of
  the 1976 COSMAC ELF microcomputer, in JavaScript.
- [Space-Invaders](https://github.com/rbscholtus/Space-Invaders): an emulator
  of the arcade Space Invaders hardware, in Java.

#### 🌐 Web apps and automation

- **[Slicktimer](https://slicktimer.app)**: a minimalist time tracker with
  instant reports, the spiritual successor to SlimTimer. SvelteKit, Firebase
  and Tailwind, installable as a PWA. *(Private source.)*
  [⏱ slicktimer.app](https://slicktimer.app)
- **[tempsecret.link](https://tempsecret.link)**: end-to-end encrypted
  one-time secret sharing: send a password or key through a link that only
  works once. *(Private source.)* [🔐 tempsecret.link](https://tempsecret.link)
- **[fujiwatch](https://github.com/rbscholtus/fujiwatch)**: a daily price
  watcher for Fujifilm X-mount gear in Vietnamese camera shops. Runs on GitHub
  Actions, sends alerts, and publishes a Svelte price-history site.
  [📈 Price history](https://rbscholtus.github.io/fujiwatch/)

#### 🧰 Tools, teaching and experiments

- [survivalist-gamedata](https://github.com/rbscholtus/survivalist-gamedata):
  a Python tool (on PyPI) that extracts crafting recipes and items from
  *Survivalist: Invisible Strain*. Its output powers two
  [Steam Community guides](https://steamcommunity.com/sharedfiles/filedetails/?id=2987340791).
- [go-webalizer](https://github.com/rbscholtus/go-webalizer): a web server log
  analyser in Go, with monthly charts and a world map of visitors.
- [piedventure](https://github.com/rbscholtus/piedventure): the BashVenture
  text adventure ported to Python with GPT-4o, as an experiment in AI code
  translation.
- [pandas_notebooks](https://github.com/rbscholtus/pandas_notebooks): the
  notebooks from my *Introduction to Data Analysis with Pandas* workshop at
  OpenTechSummit Vietnam 2019.
- [Image-Coder](https://github.com/rbscholtus/Image-Coder): a Java sandbox for
  students to learn pixel-based image processing by writing small code
  snippets.
- [Sniper3D](https://github.com/rbscholtus/Sniper3D): a 3D engine in Java,
  aimed at a simple but fun sniper game.
